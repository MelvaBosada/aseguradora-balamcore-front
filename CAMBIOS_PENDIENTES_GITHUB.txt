1. CAMBIOS PRINCIPALES Y FUNCIONALIDADES NUEVAS
------------------------------------------------

1.1. Modulo de siniestros y expediente

- Se amplio el listado de siniestros para consultar, buscar, filtrar, paginar,
  crear, editar, eliminar y asignar o reasignar ajustadores.
- Se agrego el detalle de siniestro en una ruta propia:
  /admin/siniestros/:id.
- Se creo un expediente dividido por pestañas para consultar:
  - Datos generales del siniestro.
  - Documentos.
  - Evidencias.
  - Evaluacion.
  - Historial.
  - Indemnizacion.
- Se agregaron modales para asignar ajustadores, capturar informacion y
  confirmar acciones.
- Se agrego el desglose de calculos de indemnizacion y los indicadores visuales
  de estados, tipos y niveles.
- Se agrego la pantalla de configuracion de siniestros para administrar
  catalogos y parametros relacionados con el flujo.
- Se agrego la papelera administrativa para consultar elementos eliminados y
  realizar las acciones disponibles sobre ellos.

1.2. Integracion de API y utilidades de siniestros

- Se agrego un cliente Axios reutilizable para las operaciones de siniestros.
- Se centralizo el envio del token de autenticacion y el encabezado
  application/json.
- Se agrego el manejo de sesiones expiradas: se elimina el token y se
  redirige al login cuando la API responde con 401.
- Se agregaron funciones para mostrar errores de validacion, fechas y montos.
- Se agrego la descarga de archivos protegidos mediante el token de sesion.
- Se agrego la consulta y cache de la marca, razon social y logotipo de la
  aseguradora del usuario.

Archivos nuevos:
- src/services/siniestroApi.js
- src/hooks/useMarcaAseguradora.js


1.3. Permisos y rutas administrativas

- Se agregaron rutas protegidas para el expediente y la configuracion de
  siniestros.
- Se agrego la ruta administrativa de papelera.
- Se ajustaron permisos y visibilidad de acciones en varias pantallas.
- Se agrego una utilidad para consultar el usuario, sus permisos y validar si
  puede autorizar evaluaciones por nivel.

1.4. Evaluaciones, evidencias e indemnizaciones

- Se reorganizo la pantalla de evaluaciones para integrarla con el nuevo flujo
  de siniestros y sus niveles de autorizacion.
- Se amplio el manejo de evidencias: consulta, filtros, visualizacion,
  descarga, eliminacion y acciones relacionadas con el expediente.
- Se mejoraron los documentos de evaluacion e indemnizacion para mostrar
  encabezados, datos y formatos de documento mas completos.
- Se agregaron o ajustaron validaciones, mensajes, estados de carga y

1.5. Polizas, coberturas y endosos

- Se agrego un modal especifico para consultar las coberturas de una poliza.
- Se mejoro el detalle de poliza y la presentacion de sus documentos y

- Se ajustaron listados, filtros, formularios y acciones de polizas por vencer

- Se agrego el componente SelectBalam y sus estilos para unificar selectores.
- Se actualizaron estilos de modales, tablas, dashboard y avisos.
- Se mejoraron formularios y acciones de clientes, bienes, coberturas,
